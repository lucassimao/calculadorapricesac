# Marketing Site — Calculadora Price & SAC

PT‑BR marketing site for the app, built with Next.js (App Router).

## Dev
```bash
pnpm install
pnpm dev
```

## Deploy (Vercel)
Set the project root to `marketing/`.

## Store URLs (placeholders)
Update links in `app/page.tsx` when the store pages are ready.

## Optional env vars (Twitter App Card)
Set these in Vercel if you want app‑card tags:
- `NEXT_PUBLIC_SITE_URL`
- `NEXT_PUBLIC_APP_STORE_ID`
- `NEXT_PUBLIC_APP_STORE_URL` (custom URL scheme)
- `NEXT_PUBLIC_PLAY_STORE_ID`
- `NEXT_PUBLIC_PLAY_STORE_URL` (custom URL scheme)
